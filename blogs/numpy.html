Learning NumPy in Python

Python • NumPy • Arrays • Data Analysis

Introduction

NumPy is one of the most important Python libraries for numerical computing and data analysis. It helps us perform mathematical operations efficiently and work with large amounts of numerical data.

During my Data Analysis learning journey, I started learning NumPy to understand arrays, mathematical operations, indexing, slicing and other important concepts used in data analysis.

What is NumPy?

NumPy stands for Numerical Python. It is an open-source Python library that provides support for multidimensional arrays and mathematical functions.

NumPy arrays make it easier to perform calculations on multiple values without writing separate operations for every element.

Why Do We Use NumPy?

NumPy is widely used in Data Analysis, Data Science, Machine Learning and scientific computing.

  • Perform numerical calculations efficiently.
  • Create and manipulate arrays.
  • Calculate sum, mean, minimum and maximum values.
  • Access and filter array elements.
  • Work with multidimensional data.
  • Support libraries such as Pandas and Scikit-learn.

Installing NumPy

If NumPy is not installed in your Python environment, you can install it using pip. 


pip install numpy

Importing NumPy

After installing NumPy, import it into your Python program. The alias np is commonly used as a short name for NumPy. 


import numpy as np

Creating a NumPy Array

The array() function converts a Python list into a NumPy array. 


import numpy as np

numbers = np.array([10, 20, 30, 40, 50])

print(numbers)

Output:


[10 20 30 40 50]

In this example, we created a one-dimensional array containing five numbers.

Python List vs NumPy Array

Python lists and NumPy arrays both store multiple values, but their multiplication behavior is different. 


import numpy as np

numbers = [1, 2, 3]
arr = np.array([1, 2, 3])

print(numbers * 2)
print(arr * 2)

Output:


[1, 2, 3, 1, 2, 3]
[2 4 6]

Multiplying a Python list by 2 repeats the list. Multiplying a NumPy array by 2 multiplies every element by 2.

NumPy Array Properties

NumPy provides useful properties to understand the structure and data type of an array. 


import numpy as np

arr = np.array([[1, 2, 3], [4, 5, 6]])

print("Dimensions:", arr.ndim)
print("Shape:", arr.shape)
print("Size:", arr.size)
print("Data Type:", arr.dtype)

Output:


Dimensions: 2
Shape: (2, 3)
Size: 6
Data Type: int64

The exact integer data type may vary depending on the platform and how the array is created.

  • ndim: Returns the number of dimensions.
  • shape: Returns the number of rows and columns.
  • size: Returns the total number of elements.
  • dtype: Returns the data type of the elements.

Mathematical Operations in NumPy

NumPy provides built-in functions to perform common mathematical calculations on arrays. 


import numpy as np

arr = np.array([10, 20, 30, 40, 50])

print("Sum:", np.sum(arr))
print("Mean:", np.mean(arr))
print("Minimum:", np.min(arr))
print("Maximum:", np.max(arr))
print("Standard Deviation:", np.std(arr))

Output:


Sum: 150
Mean: 30.0
Minimum: 10
Maximum: 50
Standard Deviation: 14.142135623730951

These functions are useful for understanding numerical data and calculating basic statistics.

Indexing in NumPy

Indexing allows us to access individual elements of an array. NumPy indexing starts from zero. 


import numpy as np

arr = np.array([10, 20, 30, 40, 50])

print(arr[0])
print(arr[2])
print(arr[-1])

Output:


10
30
50

Slicing in NumPy

Slicing allows us to select a portion of an array using a start index and an end index. The end index is excluded. 


import numpy as np

arr = np.array([10, 20, 30, 40, 50])

print(arr[1:4])

Output:


[20 30 40]

Reshaping an Array

The reshape() function changes the shape of an array without changing its data. The new shape must contain the same total number of elements. 


import numpy as np

arr = np.array([1, 2, 3, 4, 5, 6])

new_arr = arr.reshape(2, 3)

print(new_arr)

Output:


[[1 2 3]
 [4 5 6]]

Filtering Array Elements

We can use a condition to select specific elements from a NumPy array. 


import numpy as np

arr = np.array([10, 15, 20, 25, 30])

result = arr[arr > 20]

print(result)

Output:


[25 30]

This example selects only the elements greater than 20. Conditional filtering is useful when working with datasets.

Applications of NumPy

NumPy is used in many areas of programming and data-related work, including:

  • Data Analysis and Data Science
  • Machine Learning
  • Statistical calculations
  • Scientific computing
  • Image processing
  • Numerical data processing
