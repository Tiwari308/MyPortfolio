Learning FastAPI

Python • FastAPI • REST API

Introduction

FastAPI is a modern Python framework used to build APIs. During my Python learning journey, I started learning FastAPI to understand how APIs work and how applications communicate with each other.

What is FastAPI?

FastAPI is used to create APIs quickly and efficiently. It supports data validation and automatic API documentation.

Installing FastAPI

We can install FastAPI using pip. 


pip install "fastapi[standard]"

Creating My First API

Create a file named main.py and write the following code. 


from fastapi import FastAPI

app = FastAPI()

@app.get("/")
def home():
    return {"message": "Hello, World!"}

Here, FastAPI creates an application, and the GET endpoint returns a simple JSON response.

Running the API

Run the following command in the terminal. 


python -m uvicorn main:app --reload

Open http://127.0.0.1:8000 in your browser to see the response.

We can also test our API using the automatic documentation at http://127.0.0.1:8000/docs.
