DATA VISUALIZATION

Learning Matplotlib & Seaborn

Python • Matplotlib • Seaborn • Data Visualization

Introduction

Data visualization is an important part of data analysis. It helps us understand patterns, trends and relationships in a dataset through charts and graphs.

During my Data Analysis learning journey, I started using Matplotlib and Seaborn to create different types of visualizations using Python.

What is Matplotlib?

Matplotlib is a popular Python library used to create charts and graphs. It can be used to create line charts, bar charts, histograms, scatter plots and many other visualizations.

Importing Matplotlib


import matplotlib.pyplot as plt

Creating a Line Chart

A line chart can be used to show changes or trends over time. 


import matplotlib.pyplot as plt

months = [1, 2, 3, 4]
sales = [1000, 1500, 1200, 1800]

plt.plot(months, sales)

plt.title("Monthly Sales")
plt.xlabel("Month")
plt.ylabel("Sales")

plt.show()

Bar Chart

Bar charts are useful for comparing different categories. 


import matplotlib.pyplot as plt

products = ["A", "B", "C", "D"]
sales = [100, 150, 120, 180]

plt.bar(products, sales)

plt.title("Product Sales")
plt.xlabel("Products")
plt.ylabel("Sales")

plt.show()

Histogram

A histogram helps us understand the distribution of numerical data. 


plt.hist(data["Age"], bins=10)

plt.title("Age Distribution")
plt.xlabel("Age")
plt.ylabel("Frequency")

plt.show()

What is Seaborn?

Seaborn is a Python visualization library built on top of Matplotlib. It provides a simple way to create attractive and informative statistical visualizations.

Importing Seaborn


import seaborn as sns

Distribution Plot

Seaborn can be used to visualize the distribution of numerical data. 


sns.displot(data=data, x="Age", kde=True)

plt.show()

Histogram using Seaborn


sns.histplot(data=data, x="Sales", kde=True)

plt.show()

Relationship Between Variables

The relplot() function can help visualize the relationship between two variables. 


sns.relplot(
    x="TV",
    y="Sales",
    data=data
)

plt.show()

Pairplot

A pairplot is useful for understanding relationships between multiple numerical columns in a dataset. 


sns.pairplot(data)

plt.show()

Heatmap

A heatmap can be used to visualize correlations between numerical variables. 


sns.heatmap(
    data.corr(),
    annot=True
)

plt.show()
