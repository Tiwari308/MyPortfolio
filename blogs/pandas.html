DATA ANALYSIS

Introduction to Pandas

Python • Pandas • Data Analysis

Introduction

Pandas is one of the most popular Python libraries used for data analysis and data manipulation. It makes it easier to work with structured data such as CSV files, Excel files and database tables.

I started learning Pandas as part of my journey toward becoming a Data Analyst. It helped me understand how to load, clean, analyze and organize datasets using Python.

What is Pandas?

Pandas provides two important data structures:

  • Series – A one-dimensional data structure.
  • DataFrame – A two-dimensional table-like data structure.

Creating a DataFrame

A DataFrame can be created using a Python dictionary: 


import pandas as pd

data = {
    "Name": ["Gopal", "Raju", "Amit"],
    "Age": [22, 25, 24],
    "City": ["Mumbai", "Pune", "Delhi"]
}

df = pd.DataFrame(data)

print(df)

Reading a CSV File

One of the most common tasks in data analysis is reading data from a CSV file. 


import pandas as pd

df = pd.read_csv("data.csv")

print(df)

head() and tail()

The head() function displays the first few rows of a dataset. 


df.head()

The tail() function displays the last few rows. 


df.tail()

Understanding Dataset Information

The info() function provides useful information about columns, data types and missing values. 


df.info()

Using describe()

The describe() function provides statistical information such as count, mean, standard deviation, minimum and maximum values. 


df.describe()

Checking Missing Values

Missing values are common in real-world datasets. Pandas provides simple functions to identify them. 


df.isnull().sum()

This shows the number of missing values in each column.

Filtering Data

Pandas allows us to filter rows based on conditions. 


df[df["Age"] > 23]

GroupBy

The groupby() function is useful when we want to summarize data based on a particular column. 


df.groupby("City")["Age"].mean()
